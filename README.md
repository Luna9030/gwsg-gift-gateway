Change a resource later

Open index.html in the repository and select the pencil-shaped Edit button. Search for one of these comments:

EXERCISE WELL
EAT WELL
SCREEN WELL
SLEEP WELL

Immediately below each comment is the destination:

href="CURRENT_RESOURCE_LINK"

Replace only the text between the quotation marks, then select Commit changes. GitHub Pages will republish the updated version automatically.
